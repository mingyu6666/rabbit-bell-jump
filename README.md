# 🐰 小兔跳铃铛（微信小程序版）

复刻经典休闲小游戏《兔子跳铃铛 / Winterbells》：可爱的小兔踩着一串铃铛向夜空攀登，
踩中铃铛就会继续弹起，踩空就会摔落。越往高处，铃铛越小、间距越大，挑战你的操作与节奏感。

纯原生微信小程序实现，零第三方依赖，全部画面用 Canvas 2D 程序化绘制（含星空、云朵、雪地），
音效为脚本合成，可直接在微信开发者工具中运行。

## ✨ 玩法

- **点击/触摸开始**：小兔自动向上弹跳
- **按住屏幕左右拖动**：控制小兔的水平位置，瞄准下一个铃铛
- **踩中铃铛**：继续弹起，+1 分（金色铃铛 +5 分）
- **踩空**：小兔摔落，游戏结束
- **星星**：层间随机出现的星星，碰到 +3 分
- **难度递增**：分数越高，铃铛越小、层间距越大，20 分后还会出现双铃铛选择
- **本地记录**：历史最高分保存在本地缓存；支持微信分享好友/朋友圈

## 🚀 本地运行

**方式一：浏览器立即试玩（无需任何工具）**

直接用浏览器打开 `preview/index.html` 即可玩（鼠标拖动控制，手机浏览器支持触摸）。游戏逻辑与微信小程序完全一致，音效用 WebAudio 实时合成，进度存于浏览器本地。

**方式二：微信开发者工具运行**

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → 导入项目 → 选择本目录
   - AppID 可先选择「测试号」（`project.config.json` 已配置为游客模式 `touristappid`，导入时也可改用自己的 AppID）
3. 编译后即可在模拟器中游玩（推荐用「真机调试」体验手感）

> 提示：游戏依赖 `wx.getWindowInfo()`（基础库 2.20.1+）与 Canvas 2D 接口，开发者工具请使用较新的基础库版本。

## 🎮 游戏逻辑速览（便于二次开发）

| 模块 | 位置 | 说明 |
| --- | --- | --- |
| 物理 | `update()` | 重力 `G=2200` px/s²，踩铃铛弹起初速 `v=√(2·G·层距)` |
| 碰撞 | `update()` | 兔子脚部跨过铃铛层中心线时判定水平距离 |
| 难度曲线 | `nextGap()` / `bellRadius()` | 层距 `90→160`，铃铛半径 `38→16` |
| 相机 | `update()` | 只向上跟随（坠落时锁定，保证能掉出屏幕） |
| 渲染 | `render()` | 背景/星空/云/铃铛/兔子/粒子/雪地全部 Canvas 绘制 |
| 音效 | `initAudio()` | `wx.createInnerAudioContext` 复用三个实例 |
| 最高分 | `gameOver()` | `wx.setStorageSync` 本地缓存 |
